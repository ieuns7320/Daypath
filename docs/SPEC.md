# Daypath 기획서

> 하루하루가 목표로 이어지는 길: 일정, 할 일, 로드맵을 하나로 관리하는 개인용 앱

- 작성일: 2026-11-06
- 상태: 기획 확정 (개발 전)

---

## 1. 개요

| 항목 | 내용 |
|---|---|
| 목적 | 본인이 직접 사용하는 일정·할 일·목표 관리 앱 |
| 사용자 | 1인 (개인용) |
| 지원 기기 | 아이패드, Windows PC, 맥북, 휴대폰 |
| 형태 | 반응형 웹앱 (PWA), 홈 화면 설치 지원 |
| 동기화 | 계정 기반 클라우드 동기화 (여러 기기) |
| 오프라인 | 지원하지 않음 (현재 범위 밖) |
| 차별점 | 로드맵(목표 → 마일스톤 → 일정/할 일) 연결과 진행률 자동 계산 |

## 2. 기술 스택

| 영역 | 선택 | 이유 |
|---|---|---|
| 프론트엔드 | React (Next.js) | 생태계가 크고 PWA 구성이 쉬움 |
| 캘린더 UI | FullCalendar | 일간/주간/월간, 드래그·리사이즈, 터치 기본 지원 |
| 백엔드 / DB | Supabase | 로그인, Postgres DB, 실시간 동기화, 예약 작업(알림) |
| 배포 | Vercel | 무료, Git 연동 자동 배포 |
| 알림 | Web Push | PWA 푸시 알림 |

비용: 개인 사용 규모에서는 무료 티어로 운영 가능.

## 3. 핵심 개념

### 일정 (Event)과 할 일 (Task)는 별개

| | 일정 | 할 일 |
|---|---|---|
| 본질 | 특정 시간에 일어나는 일 | 해야 하는 일 |
| 시간 | 시작/종료 일시 (필수) | 마감일 (선택) |
| 종일 / 여러 날 | 지원 | 해당 없음 |
| 반복 | 지원 | **지원 안 함** |
| 완료 체크 | 없음 | 있음 |
| 시간 배치 | 기본 속성 | 타임 블로킹으로 "작업 시간" 배정 가능 |
| 캘린더 모양 | 카테고리 색으로 칠한 블록 | 체크박스 (배치 시 점선 테두리 블록) |

### 카테고리와 태그

| | 카테고리 | 태그 |
|---|---|---|
| 개수 | 항목당 **1개** | 항목당 **여러 개** |
| 색상 | 있음 (캘린더 블록 색) | 있음 (블록 안 작은 칩/점) |
| 필터 | 지원 | 지원 |

- 색상은 라이트/다크 모드 양쪽에서 잘 보이도록 조정한 **프리셋 팔레트(8~10색)**에서 선택.

### 로드맵 (B 형식: 계층형)

```
목표 (Goal)
 └ 마일스톤 (Milestone)
     ├ 할 일 (Task)   → 진행률 계산에 포함
     └ 일정 (Event)   → "관련 일정"으로만 표시, 진행률 제외
```

- 마일스톤 진행률 = 연결된 할 일 중 완료된 비율
- 목표 진행률 = 하위 마일스톤 진행률 종합

## 4. 데이터 구조 (개념)

| 엔티티 | 주요 속성 |
|---|---|
| **Event** | 제목, 시작 일시, 종료 일시, 종일 여부, 카테고리, 태그[], 반복 규칙, 알림[], 메모, 마일스톤(선택) |
| **Task** | 제목, 마감일(선택), 작업 시간 시작/종료(선택, 타임 블로킹), 완료 여부, 완료 일시, 카테고리, 태그[], 알림[], 메모, 마일스톤(선택) |
| **Category** | 이름, 색상, 정렬 순서 |
| **Tag** | 이름, 색상 |
| **Goal** | 제목, 설명, 시작일, 목표일 |
| **Milestone** | 제목, 소속 목표, 목표일, 정렬 순서 |
| **RecurrenceRule** | 반복 단위(일/주/월/년), 간격, 요일, 종료 조건, 예외 날짜 |
| **Reminder** | 대상(일정/할 일), 알림 시점(상대 시간) |
| **PushSubscription** | 기기별 웹 푸시 구독 정보 |

반복 일정 수정 시 선택지: **이 일정만 / 이후 모든 일정 / 전체 일정**

## 5. 화면 구성

### 5.1 전체 레이아웃

- **데스크톱 / 아이패드 가로**: 왼쪽 사이드바 (캘린더 · 할 일 · 로드맵 · 카테고리 목록 · 태그 목록 · 설정) + 메인 영역
  - 사이드바의 카테고리/태그 클릭 시 필터로 동작
- **모바일**: 상단 헤더 (기간 이동, 일/주/월 전환) + 하단 탭바 (캘린더 · 할 일 · 로드맵 · 설정)
- 공통: 우측 하단 `+` 빠른 추가 버튼

### 5.2 캘린더 탭

- 보기 전환: **일간 / 주간 / 월간**
- 한 주의 시작: **일요일**
- 모바일 주간 보기는 **3일 보기**를 기본으로 함

**일간 / 주간 (시간축 타임라인)**
```
        일        월        화
      ┌────────┬────────┬────────┐
종일   │■ 출장 ──────────────▶   │   ← 종일·여러 날 일정
할 일  │☐ 보고서 │☑ 장보기 │☐ 과제   │   ← 마감일 있는 할 일
      ├────────┼────────┼────────┤
09:00 │■ 회의   │        │        │   ← 시간 일정 (카테고리 색 블록)
10:00 │        │┊☐ 보고서┊│        │   ← 작업 시간을 배정한 할 일 (점선)
      └────────┴────────┴────────┘
```

**월간**
- 일정: 카테고리 색 막대, 칸이 넘치면 "+N개 더"
- 할 일: 날짜 칸에 `☐ 3`처럼 개수만 요약, 클릭 시 펼침

**드래그 (1단계부터 필수, 마우스와 터치 모두 지원)**
- 일정 블록 드래그 → 시간/날짜 이동
- 일정 블록 끝 드래그 → 기간 조절
- 빈 시간대 드래그 → 해당 범위로 새 일정 추가 창 열기
- 할 일 드래그 → 타임라인에 작업 시간 배정 (2단계)

**표시 옵션**
- "할 일 표시" ON/OFF 토글
- 완료한 할 일은 흐리게 표시하고 취소선 처리

### 5.3 일정 / 할 일 추가·수정 창

```
┌─────────────────────────────────┐
│  [ 일정 | 할 일 ]          ✕    │
├─────────────────────────────────┤
│  제목                            │
│  🕐 날짜·시간   ☐ 종일  ↻ 반복    │
│  ■  카테고리                      │
│  #  태그 (여러 개)                │
│  🔔 알림 (여러 개)                │
│  ◎  로드맵 연결 (마일스톤)         │
│  ≡  메모                         │
├─────────────────────────────────┤
│                [삭제]  [ 저장 ]  │
└─────────────────────────────────┘
```
- 할 일 모드: 시간 대신 "마감일(선택)", 반복 항목 숨김, 완료 체크 표시
- 데스크톱은 가운데 팝업, 모바일은 하단 시트

### 5.4 할 일 탭

- 그룹: **지난 마감 / 오늘 / 이번 주 / 이후 / 마감일 없음 / 완료됨(접힘)**
- 정렬: 마감일순, 생성순
- 필터: 카테고리, 태그
- 데스크톱: 할 일 목록과 주간 캘린더를 나란히 띄워 **타임 블로킹 모드** 지원

### 5.5 로드맵 탭

- **트리 보기**: 목표 → 마일스톤 → 할 일/일정 계층, 각 단계 진행률 막대
- **타임라인 보기**: 목표와 마일스톤을 시간축 가로 막대로 표시
- 목표/마일스톤 추가·수정·삭제

### 5.6 설정

- 테마: 시스템 / 라이트 / 다크
- 카테고리 관리 (이름, 색상, 순서)
- 태그 관리 (이름, 색상)
- 알림 권한 및 기본 알림 시점
- 계정 (로그아웃)

## 6. 알림

| 대상 | 알림 시점 |
|---|---|
| 일정 | 정시, 10분 전, 1시간 전, 하루 전 등 (여러 개 선택) |
| 할 일 | 마감일 당일 아침, 하루 전 / 작업 시간 시작 시 |

- 서버 예약 작업(Supabase)이 정해진 시간에 Web Push 발송
- **제약**: iPhone/iPad는 PWA를 "홈 화면에 추가"해야 푸시 수신 가능 (iOS 16.4 이상)

## 7. 디자인 원칙

- **미니멀**: UI는 흑백·회색 톤, 색은 카테고리/태그 데이터에만 사용
- 테두리·그림자 대신 여백과 1px 구분선으로 영역 구분
- **다크 모드** 지원 (기본값: 시스템 설정 따름)
- 일정 = 칠해진 블록, 할 일 = 체크박스로 생김새부터 구분

## 8. 개발 단계 (MVP 로드맵)

| 단계 | 범위 |
|---|---|
| **1단계** | 프로젝트 세팅, 로그인/동기화, 일정 CRUD (종일·여러 날 포함), 카테고리·태그 (색상), 일간/주간/월간 보기, 드래그 이동·리사이즈, 다크 모드 |
| **2단계** | 할 일 탭 (완료 체크, 마감일), 캘린더에 할 일 표시, 타임 블로킹, 카테고리/태그 필터 |
| **3단계** | 반복 일정, 알림 (Web Push) |
| **4단계** | 로드맵 탭 (목표 → 마일스톤 → 일정/할 일 연결, 진행률, 트리/타임라인 보기) |

## 9. 범위 밖 (현재 제외)

- 반복 할 일
- 오프라인 사용
